# 目录结构说明

## 一、项目目录（代码与数据）

```

│

├── bin/                      双击即用的入口

│   ├── 2-拉取数据.command      ② 把沙盒数据搬到 data/
```

## 二、导出成品（`export/`）

```
export/
├── index.html            ★ 总索引：所有会话一行一个，能搜索、能点进去
├── 总览.csv                 全部会话统计（Excel 直接打开，UTF-8 BOM）
├── _manifest.json           进度记录；重跑时会跳过已完成的会话
│
├── 群聊/
│   └── <群名>/               重名时自动加会话 ID 后缀
│       ├── 聊天记录.html       阅读版（消息 > 2 万条时这里是按月目录页）
│       ├── 聊天记录.txt        纯文字版，方便 grep
│       ├── 聊天记录.csv        Excel 版（含「发送者wxid」列）
│       ├── 成员名单.html/.csv   ★ 成员：群内显示名/群昵称/备注/微信昵称/
│       │                          微信号/wxid/发言数/身份
│       ├── 说明.txt            本会话的类型统计与覆盖情况
│       ├── 图片/               文件名 = 时间_发送者_编号.扩展名
│       ├── 附件/               PDF / ZIP / MP4 等原样带出
│       └── 分月/               仅超大会话：2026-01.html、2026-02.html…
│
├── 私聊/
│   └── <显示名>/             备注 → 群昵称 → 微信昵称 → 微信号
│       └── （与群聊同构，但没有成员名单）
│
├── 最近记录/                 recent.py 生成的「最近 N 天」视图，按天分页
│
└── 共享资源/
    └── 表情包/
        ├── <md5>.gif         全局去重，所有会话共用
        └── _index.txt        md5 / 出现次数 / 描述 / CDN 地址
```

### 为什么表情包单独放

同一个表情会在几十个会话里反复出现。如果每个会话目录各存一份，
体积会翻好几倍。所以统一放在 `export/共享资源/表情包/`，
各会话的 HTML 用相对路径（`../../共享资源/表情包/xxx.gif`）引用。

**整个 `export/` 目录可以整体搬走**，相对路径不会失效。

### 为什么超大会话要分月

单文件 HTML 到几万条消息时浏览器会明显卡顿（DOM 节点太多）。
默认超过 2 万条就按月拆分，主文件变成目录页并保留搜索框。

## 三、哪些能删

| 目录 | 大小 | 能删吗 | 说明 |
|---|---|---|---|
| `keys/` | 几 KB | **别删** | 删了要重新抓密钥（要重启微信 + 重新登录） |
| `data/` | 视账号 | 能删 | 删了重跑 `clone_data.py` 即可 |
| `export/` | 视内容 | 能删 | 删了重跑 `export_all.py` |
| `.runtime/` | 视情况 | 能删 | 只在抓密钥/搬数据时用到 |
| `.venv/` | ~200 MB | 能删 | 删了要重装依赖 |
